# Pipeline Execution Dashboard

The aggregated execution dashboard generated by [`generate_report.py`](../api/generate_report.md) provides operational visibility across entire batch runs.

---

## Dashboard Architecture

The dashboard compiles data from all `product_detail.json` files within an output directory and builds a standalone HTML5 application featuring **Chart.js** dynamic data visualizations:

```text
+-------------------------------------------------------------------------------+
| HEADER: Pipeline Execution Report    [ Total Processed: 50 ]  [Reset Filters] |
+-------------------------------------------------------------------------------+
| KPI SUMMARY CARDS                                                             |
| [Success: 46] [Fail: 4] [Try 1: 38] [Try 2: 6] [Try 3: 2] [Tokens: 1.2M] [$] |
+---------------------------------------+---------------------------------------+
| CHART 1: Score Distribution (Line)    | CHART 2: Status by Category (Stacked) |
| [Interactive clickable score bands]   | [Clickable bars to filter products]   |
+---------------------------------------+---------------------------------------+
| PRODUCT GRID (Dynamic Responsive Cards)                                       |
| [Card 1: WPID 101] [Card 2: WPID 102] [Card 3: WPID 103] [Card 4: WPID 104]  |
+-------------------------------------------------------------------------------+
```

---

## Interactive Features

### 1. Interactive Score Band Filtering
Clicking any point on the **Score Distribution** chart filters the product grid in real time to display only SKUs whose best likeness score falls within the selected band (e.g., `80-89%`, `90-100%`).

### 2. Category Drilldown Filtering
Clicking any category bar in the **Status by Category** stacked bar chart isolates SKUs matching that category hierarchy.

### 3. KPI Telemetry Summary Cards
- **Outcome Metrics**: Total processed, success count, failure count.
- **Retry Distribution**: Count of products succeeding on Try 1, Try 2, Try 3, Try 4, Try 5, or Failed.
- **Resource Consumption**: Total input tokens, total output tokens, calculated dollar cost.
- **Reliability & Performance**: Total retries, median retries to pass, HTTP error counts grouped by status code, average/min/max execution latency.

## Standalone Execution

Regenerate the dashboard from an existing output directory without re-running the GenAI pipeline:

```bash
uv run product-gen-report --dir output/Google_50_skus_image_generation
```
